# GUI 接入位置

GUI 暂定使用 **FLTK**，但当前不实现界面、不下载依赖、不注册 GUI 构建目标。

先完成真实资源的核心与 CLI 验证，再在此目录加入 GUI：

- 直接链接 `eagls::core`，调用与 CLI 相同的公共操作。
- 此处负责控件、展示模型和后台任务调度；不把 FLTK 头文件或类型带入核心公开接口。
- 耗时操作不占用 UI 线程；进度回调先经过 GUI 线程适配，再更新控件。
- 不通过启动 CLI 并解析标准输出来复用业务逻辑。
- 不预先承诺完整翻译编辑器，功能随真实工作流逐步确定。

详细边界见 [架构设计](../../docs/architecture.md)。
